# Changelog

Todas las versiones notables de Aetherbook se documentan acá. Cada entrada
la genera `tool/release.sh` a partir de los commits desde el tag anterior,
agrupados por su prefijo [Conventional Commits](https://www.conventionalcommits.org/es/v1.0.0/)
(ver CLAUDE.md §13 para el formato exacto y cómo cortar un release).

El historial previo a la primera entrada de abajo no se versionó con este
esquema — 120 commits sin tag, `pubspec.yaml` quedó en `1.0.0+1` desde el
scaffold inicial de Flutter.
